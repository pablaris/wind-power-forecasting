# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

IE University ML project: forecasting hourly wind generation (MW) in the 8 Spanish provinces with the
highest wind output, from meteorological predictors. The data covers 2021-01-01 to 2023-12-31.

## Environment

- Use the conda env `machine_learning` (Python 3.12+), and activate it before running anything. On Windows, running the env's `python.exe` without activating the env makes numpy crash with `0xc06d007f`.
- `pip install -r requirements.txt`
- The ESIOS loader needs `ESIOS_TOKEN` in a `.env` file at the repo root. The file is gitignored and may be saved with a BOM, which is why the loader reads it with `utf-8-sig`.

There is no test suite, linter or build step.

## Data pipeline

`data/` is gitignored and is fully generated by these scripts. Run them in this order from the repo root:

```bash
python src/loaders/esios_client.py        # ESIOS indicator 10037 -> data/raw/esios/generacion_eolica.csv
python src/loaders/open_meteo_client.py   # Open-Meteo archive    -> data/raw/open_meteo/meteorology.csv
python src/processing/merge_datasets.py   # inner join            -> data/processed/dataset.csv (~210k rows)
python src/eda/eda_esios.py               # figures               -> reports/figures/
```

How the pipeline fits together:
- **Scripts:** each one is a flat top-level script with no functions to import, and it resolves paths relative to its own file (`os.path.dirname(__file__)/../..`).
- **Province names across sources:**
  - The ESIOS loader picks the top 8 provinces dynamically, by total generation.
  - The Open-Meteo loader uses a hardcoded `PROVINCIAS` dict of lat/lon points.
  - The merge is an **inner join on `datetime` + `provincia`**, so names must match ESIOS's `geo_name` exactly (accents included, e.g. `Cádiz`, `A Coruña`). A mismatch drops that province silently.
- **ESIOS download behavior:** the loader downloads month by month with retries. It refuses to save anything if any month fails.
- **Timestamps:** all are UTC. Parse them with `pd.to_datetime(..., utc=True)`.

## Dataset schema (`data/processed/dataset.csv`)

- Keys: `datetime`, `provincia`
- Target: `generacion_mw`
- Features (wind speed is in m/s):
  - `wind_speed_100m`, `wind_direction_100m`
  - `wind_gusts_10m`, `temperature_2m`, `pressure_msl`

Column names, comments and some print output are a mix of Spanish and English. Keep the existing column names.

## Notebooks

Notebooks in `notebooks/` are meant to import their logic from `src/`. They read data with paths relative to `notebooks/`, such as `../data/processed/dataset.csv`, so run Jupyter from inside that folder or adjust the paths.
